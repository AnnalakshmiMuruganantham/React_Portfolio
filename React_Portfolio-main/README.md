# Annalakshmi N M — Portfolio

This is the updated React + Vite portfolio source.

## Run locally

1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Publish the changes

1. Extract this ZIP.
2. Replace the files in your existing GitHub repository with the contents of this folder (keep the repository's `.git` folder if you are working from a local clone).
3. Commit and push the changes to the branch connected to Vercel.
4. Vercel should build and deploy the updated site automatically.
